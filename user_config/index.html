通知设置

当被选中的事件发生时，系统会发送一则通知到你的通知中心。

有人回复你的评论
有人在你的帖子下留言
有人阅读你回复他的评论
有人点赞你的帖子
有人操作你的帖子(置顶/关闭/删除,仅管理员可操作)

绑定电子邮箱

绑定电子邮箱后，有人回复你的评论时，或者有人在你的帖子下评论时，你的电子邮箱将会收到一封提醒邮件，点击邮件中的链接可以快速跳转到评论位置。

支持绑定任何域名邮箱，一个电子邮箱可绑定多个账户，一个账户只能绑定一个电子邮箱，可以随时解绑。

当前绑定的电子邮箱:加载中

绑定方法: 在下面的输入框里输入要绑定的邮箱地址，点击发送验证邮件按钮，点击邮箱收到的验证邮件中的链接即可完成绑定。



如果想要解除绑定，请点击解除绑定按钮
